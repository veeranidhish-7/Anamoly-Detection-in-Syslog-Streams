# Problem Statement

This project investigates syslog anomaly detection based on the methods presented in the paper "Lightweight Optimization based Log-file Anomaly Detection" (Fält et al., ICSRS 2025). Syslog anomaly detection involves analyzing system logs to automatically identify unusual patterns that may indicate failures, security breaches, or other critical events. The "lightweight" aspect is emphasized because real-world systems generate logs at a high velocity; therefore, anomaly detection models must operate with minimal computational overhead to be practical for real-time deployment. Our objective was to independently replicate the baseline Principal Component Analysis (PCA) model described in the paper, evaluate its performance on an unseen dataset to test generalizability, and subsequently extend the methodology to handle more complex log structures.
